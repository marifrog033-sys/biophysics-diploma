# Анализ научных направлений: биофизика и биомедицина

Стартовый каркас для семантического анализа научных тем с помощью научных эмбеддингов, кластеризации и визуализации.

## Что делает проект

1. Загружает `data/raw/raw_topic_data.csv`.
2. Формирует текстовое поле из названия/описания/аннотации (столбцы настраиваются).
3. Получает эмбеддинги научных текстов с помощью предобученной модели SPECTER.
4. Подбирает число кластеров K-Means по silhouette score.
5. Сохраняет таблицу с назначенными кластерами и графики.

**Важно:** SPECTER здесь не обучается с нуля. Модель уже предобучена на научных публикациях; на наших данных выполняется инференс (получение эмбеддингов), после чего обучается алгоритм кластеризации.

## Запуск

### 1. Установить зависимости

```bash
python -m venv .venv
.venv\\Scripts\\activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 2. Положить исходный файл

Скопировать `raw_topic_data.csv` в `data/raw/`.

### 3. Настроить столбцы

Открыть `src/config.py`. Если автоматическое определение не найдёт текстовые столбцы, указать их названия в `TEXT_COLUMNS`, например:

```python
TEXT_COLUMNS = ["title", "abstract"]
```

Названия должны в точности совпадать с заголовками CSV.

### 4. Запустить

```bash
python main.py
```

При первом запуске модель SPECTER будет скачана из Hugging Face. Для этого нужен доступ к интернету.

## Результаты

Файлы появятся в `outputs/`:

- `clustered_topics.csv` — исходные строки и присвоенные кластеры;
- `embeddings.npy` — матрица эмбеддингов;
- `cluster_sizes.png` — число объектов в каждом кластере;
- `clusters_2d.png` — двумерная проекция эмбеддингов;
- `silhouette_scores.png` — качество кластеризации для проверенных значений k;
- `clustering_metrics.json` — выбранное число кластеров и метрики.

## Ограничения первого прототипа

- Пока используется один CSV — `raw_topic_data.csv`.
- Отбор биофизики/биомедицины, объединение с цитированием и анализ динамики добавим после проверки структуры всех таблиц.
- Кластеры — это математические группы, а не готовые научные категории. Их смысл нужно будет интерпретировать по наиболее характерным темам.
- Silhouette score не гарантирует научную осмысленность кластеров; это только один из критериев выбора.
